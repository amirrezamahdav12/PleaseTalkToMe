# 🎮 please talk to me

A modular, open-source dialogue system template built with **Unity 6**.

This project provides a solid foundation for creating narrative-driven games, visual novels, psychological experiences, and choice-based adventures.

## ✨ Features

- 🎭 Branching Dialogue System
- 💬 Choice-Based Conversations
- 📝 ScriptableObject Dialogue Nodes
- ❤️ Player Stats System (Hope, Stress, Trust)
- 🎥 Video Portrait System
- 🔄 Smooth Video Crossfade Transitions
- ⌨️ Typewriter Text Effect
- 🔊 Pixel Typing Audio
- 💭 Chat Message System
- 🎯 Event Ready Architecture
- 🧩 Modular & Extendable Design

---

## 📦 Built With

- Unity 6
- C#
- Unity Input System
- VideoPlayer API
- ScriptableObjects
